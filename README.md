# 디지털/기업 허브

DX디자인팀(정규직)과 협력사(디지털, 기업)가 함께 쓰는 사이트입니다. 공지사항, 팀원 휴가 일정, 협력사 월별 AX 실적 제출과 첨부 검토를 한곳에서 관리합니다.

- **화면**: 정적 HTML/JS (빌드 없음) → Vercel에 그대로 배포
- **DB · 로그인 · 첨부**: Supabase (Postgres + Auth + Storage)
- **권한**: DB의 RLS 규칙이 강제합니다. 화면을 우회해 API를 직접 호출해도 같은 규칙이 적용됩니다.

**그룹**은 두 종류입니다.
- **정규직 팀** (`internal`, 예: DX디자인팀): 휴가 달력·팀원 명단에 포함, AX 실적 표에서는 제외
- **협력사** (`partner`, 예: 디지털, 기업): 휴가·팀원 + 월별 AX 실적 제출

| 권한 | 할 수 있는 일 |
|---|---|
| DX 관리자 (`admin`) | 전부. 작성자 권한 + 공지 작성, 실적 검토(확인 완료/보완 요청)·삭제, 그룹·사용자 관리 |
| 작성자 (`partner`) | 모든 내용 열람 + **공지사항을 뺀** 팀원·휴가·AX 실적·첨부·팀원 사진을 소속과 관계없이 작성. 화면에는 정규직 소속이면 ‘팀원’, 협력사 소속이면 ‘협력사’로 표시 |
| 열람 전용 (`viewer`) | 열람만 |
| 미등록 | 로그인은 되지만 '승인 대기' 화면만 보임 |

로그인한 사람은 **내 계정**에서 프로필 사진을, 작성자는 **협력사 · 팀원**에서 팀원 명단 사진을 올릴 수 있습니다.

## 설치 (처음 한 번, 약 20분)

### 1. Supabase 프로젝트 만들기
1. https://supabase.com 에서 로그인 → **New project**
2. Region은 **Northeast Asia (Seoul)** 을 고릅니다.
3. DB 비밀번호는 안전한 곳에 보관합니다(앱에는 쓰이지 않음).

### 2. DB 만들기
1. 왼쪽 메뉴 **SQL Editor** → New query
2. `supabase/schema.sql` 전체를 붙여 넣고 **Run**
3. `supabase/seed.sql` 을 열어 `YOUR_EMAIL@medialog.co.kr` 를 **본인(첫 관리자) 이메일**로 바꾼 뒤 붙여 넣고 **Run**
   - 그룹 3개(정규직 DX디자인팀, 협력사 디지털·기업)와 기존 현황판의 2026년 4~10월 실적이 들어갑니다.

### 3. 로그인 설정
**Authentication → URL Configuration**
- **Site URL**: 배포 후 받은 주소 (예: `https://dx-partner-hub.vercel.app`)
- **Redirect URLs**: 위 주소와 로컬 확인용 `http://localhost:3000` 추가

**초대 코드로 본인이 비밀번호를 만드는 방식**을 씁니다. 아래 두 가지를 설정하세요.
- **Authentication → Sign In / Providers → Email**: **Confirm email** 을 끕니다. (회사 메일 서버를 연결하기 전에는 인증 메일이 협력사에게 가지 않기 때문)
- 같은 화면 또는 **Authentication → Settings** 의 **Allow new users to sign up** 은 켜 둡니다.

등록되지 않은 이메일이나 틀린 초대 코드로는 계정을 만들 수 없고, 코드 없이 생긴 계정은 관리자가 승인하기 전까지 아무것도 볼 수 없습니다.

> 회사 메일 서버(SMTP)를 **Authentication → Emails → SMTP Settings** 에 연결하면 이메일 로그인 링크와 비밀번호 재설정 메일도 쓸 수 있습니다. 연결 후 `config.js` 의 `EMAIL_LINK` 를 `true` 로 바꾸면 로그인 화면에 버튼이 생깁니다.

### 4. 첫 관리자 계정
1. Authentication → Users → **Add user** 로 본인 계정을 만듭니다 (seed.sql 에 넣은 이메일과 같아야 함).
2. 배포한 사이트에 로그인하면 DX 관리자로 들어갑니다.

### 5. `config.js` 채우기
**Project Settings → API** (또는 **API Keys**) 에서 복사해 `config.js` 에 넣습니다.

```js
window.HUB_CONFIG = {
  SUPABASE_URL: 'https://abcdefgh.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ... 또는 sb_publishable_...'
};
```

> anon(publishable) 키는 공개돼도 괜찮은 키입니다. **service_role / secret 키는 절대 넣지 마세요.**

### 6. GitHub → Vercel 배포
1. 이 폴더를 GitHub 저장소로 올립니다.
2. https://vercel.com → **Add New → Project** → 저장소 Import
3. Framework Preset: **Other**, Build Command: 비움, Output Directory: 비움 → **Deploy**
4. 받은 주소를 3단계의 Site URL / Redirect URLs 에 넣습니다.

이후에는 GitHub에 push 할 때마다 자동으로 다시 배포됩니다.

> 회사 GitLab을 쓰려면: GitLab.com 저장소는 Vercel에 바로 연결됩니다. 사내 설치형 GitLab은 Vercel 연결이 제한될 수 있어, 그때는 GitHub를 쓰거나 GitLab CI에서 `vercel deploy` 를 실행하는 방식으로 배포합니다.

### 로컬에서 확인
```bash
python3 -m http.server 3000
```
브라우저에서 http://localhost:3000 을 엽니다.

## 업그레이드 (이미 설치한 프로젝트)

`supabase/upgrade-*.sql` 파일을 번호 순서대로 SQL Editor에서 한 번씩 실행하세요. 여러 번 실행해도 안전합니다.

**002~004를 한꺼번에 적용하려면 `supabase/upgrade-now.sql` 하나만 실행하면 됩니다.** 결과가 `정규직팀 1 | 협력사 2 | 실적기록 14` 처럼 나오면 완료입니다.

| 파일 | 내용 |
|---|---|
| `upgrade-002-team-avatars.sql` | 정규직 팀 그룹(DX디자인팀) 추가, 프로필 사진 기능 |
| `upgrade-003-open-write.sql` | 공지사항을 뺀 작성 권한을 작성자 전원에게 개방 |
| `upgrade-004-ax-per-member.sql` | AI 이미지 실적을 협력사 팀원 개인별로 제출 (기존 회사 단위 기록은 '회사 단위(이관)'으로 유지) |
| `upgrade-005-ax-board.sql` | 자유 형식 **AX 실적** 게시판, 팀원 파트(디자인/퍼블리싱/기타) |
| `upgrade-006-invite-code.sql` | 초대 코드로 본인이 비밀번호 만들기, 관리자 승인 |
| `upgrade-007-ax-comments.sql` | **AX 실적 글 댓글** (작성자·관리자 작성, 수정은 본인만, 삭제는 본인 또는 관리자, 열람 전용은 읽기만) |
| `upgrade-008-alerts.sql` | **사이트 안 알림**의 읽음 시각을 계정별로 저장 (PC·휴대폰에서 함께 읽음 처리). 실행 전에는 기기별로만 저장됩니다 |

새로 설치하는 경우에는 `schema.sql` + `seed.sql` 만 실행하면 모두 포함돼 있습니다.

## 운영

### 팀원·협력사 담당자 추가 (초대 코드)
1. 사이트 **사용자 관리 → 사용자 등록**: 이메일, 이름, 권한 `작성자`, 소속(정규직 팀 또는 협력사) 선택 → 6자리 **초대 코드**가 자동으로 만들어집니다.
2. 목록의 **안내 복사**를 누르면 사이트 주소·이메일·초대 코드가 담긴 안내문이 복사됩니다. 본인에게 **개별로** 전달하세요(메신저·개인 메일).
3. 받은 사람은 로그인 화면의 **처음이신가요? 비밀번호 만들기**에서 이메일·초대 코드·비밀번호를 넣으면 바로 사용합니다.
4. 코드가 다른 사람에게 알려졌다면 사용자 **수정 → 코드 재발급**. 이미 계정을 만든 사람에게는 영향이 없습니다.
5. **승인 대기**: 초대 코드 없이 만들어진 계정(예: Supabase 대시보드에서 만든 계정)은 여기에 뜹니다. 본인이 맞는지 확인하고 **승인**하세요.
6. 접근을 끊을 때는 사용자 관리에서 **접근 해제**. 계정은 남지만 아무것도 볼 수 없게 됩니다.

### 비밀번호를 잊은 경우
- 메일 서버(SMTP)를 연결하기 전에는 재설정 메일을 보낼 수 없습니다. Supabase **Authentication → Users** 에서 그 사용자를 지우고, 사이트에서 **코드 재발급** 후 다시 ‘비밀번호 만들기’를 안내하세요. (그 사람이 쓴 글의 작성자 표시는 비워집니다.)
- 메일 서버를 연결하면 Supabase에서 **Send password recovery** 로 재설정 메일을 보낼 수 있습니다.

### 메뉴 구성
- **홈**: 대시보드. 오늘 휴가, 이번 달 AX 실적, 지난달 AI 이미지 적용률, 검토 대기 요약 카드 + 최근 AX 실적, 주간 일정, 공지(공지/필독 탭), AI 이미지 협력사별 막대
- **AX 실적**: 디자인·퍼블리싱·공통 파트의 AI 활용 사례·노하우·산출물을 자유 형식으로 올리는 게시판. 상태(아이디어/테스트/진행 중/완료), 활용 가능 표시, AI Tool, 분류, 중요도, 일정, 첨부, 내용. 글은 작성자 본인과 DX 관리자만 수정·삭제
- **AI 이미지 제작**: 협력사 **디자인 파트** 팀원의 월별 AI 이미지 실적과 증빙 검토 (아래 흐름)

### AI 이미지 실적 흐름
1. 협력사 디자인 파트 팀원 **개인별로** 매월 **실적 제출**: AI 이미지 제작 건수, AI 활용 제작 건수, 전체 이미지 제작 수, 증빙 첨부
   - 팀원은 ‘협력사 · 팀원’에 파트 ‘디자인’으로 먼저 등록돼 있어야 합니다. 협력사(디지털·기업)별 합계와 협력사 전체 합계는 자동으로 계산됩니다.
   - 2026년 4~10월 기존 현황판 기록은 개인별 내역이 없어 ‘회사 단위 (이관)’ 행으로 표시되고 합계에 포함됩니다.
2. DX팀이 첨부 확인 → **확인 완료** 또는 **보완 요청**(의견 필수)
3. 협력사가 다시 제출하면 자동으로 **검토 대기**로 돌아갑니다.
4. 적용률 = AI 이미지 제작 건수 ÷ 전체 이미지 제작 수 (기존 현황판과 같은 기준)

### 첨부파일
- 비공개 저장소(`attachments` 버킷). 로그인한 등록 사용자만 1시간짜리 임시 링크로 열 수 있습니다.
- 엑셀·PPT·ZIP 포함 모든 형식, 파일당 50MB (Supabase 무료 플랜 상한).
- 작성자는 실적 첨부(`ax/`)와 팀원 사진(`avatars/members/`)을, 모든 로그인 사용자는 본인 프로필 사진을 올릴 수 있습니다. 공지 첨부는 DX 관리자만 올립니다.

### 공휴일
`app.js` 맨 위 `HOLIDAYS` 에 2026년 공휴일이 들어 있습니다. 매년 초 다음 해 공휴일을 추가하세요.

### 무료 플랜에서 알아둘 것
- DB 500MB, 파일 1GB, 파일당 50MB
- **7일 동안 아무도 접속하지 않으면 프로젝트가 일시정지**됩니다. 대시보드에서 Restore 하면 데이터는 그대로 돌아옵니다. 상시 운영이 중요하면 Pro 플랜을 고려하세요.
- 자동 백업은 Pro 플랜부터입니다. 무료 플랜에서는 가끔 사이트의 **엑셀 내보내기 → 전체 백업 → 한꺼번에 받기 (ZIP)** 로 내용을 내려받아 두세요. (휴가·AI 이미지 실적·AX 실적 글·댓글·팀원 명단·공지가 CSV로 들어 있습니다. 첨부파일은 들어가지 않습니다. DB를 그대로 되살리는 용도가 필요하면 Supabase **Table Editor → Export to CSV** 도 함께 받아 두세요.)
- **엑셀 내보내기**: 휴가 일정·AX 실적·AI 이미지 제작·협력사·팀원 화면 오른쪽 위 버튼(관리자·작성자). 엑셀에서 바로 열리는 CSV로 저장됩니다.
- **AI 이미지 실적 독려**: AI 이미지 제작 화면의 **○월 제출 현황**에서 미제출·보완 요청 대상을 확인하고, **안내 문구 복사**로 메신저에 붙여 넣을 문구를 복사합니다(협력사별 복사 가능).

## 파일 구조
```
index.html            화면 틀과 스타일 (라이트/다크 토글 포함)
app.js                화면 동작, Supabase 연결
config.js             Supabase URL / anon 키  ← 직접 채움
vendor/               supabase-js 2.117.3 브라우저 빌드 (CDN 차단된 사내망 대비)
supabase/schema.sql   테이블, 권한(RLS), 트리거, 첨부 저장소
supabase/seed.sql     그룹(DX디자인팀·디지털·기업), 첫 관리자, 2026년 4~10월 실적
supabase/upgrade-*.sql 기존 프로젝트 업그레이드용
vercel.json           보안 헤더, 검색 노출 차단
```
